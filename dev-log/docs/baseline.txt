*** KEY FINDING: A REFLASH IS PROBABLY AVOIDABLE ***
  dpkg -S on the DTBs returns "no path found" — they are not tracked directly.
  But the installed package list explains why:

    u-boot-efi-dtb  3  "copy DTBs to the EFI System Partition
                        from the linux-image-* packages"
    linux-image-6.16.7-g0dd6551ae96b  6.16.7-g0dd6551ae96b-1

  DTBs are delivered BY the linux-image-* package and copied to the ESP by
  u-boot-efi-dtb. Arduino's own apt repo is configured:

    deb [signed-by=/etc/apt/keyrings/arduino.asc] https://apt-repo.arduino.cc stable main

  => a newer linux-image-* from apt-repo.arduino.cc should install the
     carrier-media overlays into /boot/efi/dtb/qcom/ without an EDL reflash.
     Try `apt full-upgrade` FIRST; keep the reflash as the fallback.
