*** IMPORTANT CORRECTION TO THE ROLLBACK PLAN ***
  EFI variables are READ-ONLY on this platform:
    bootctl set-default -> "Failed to update EFI variable ...: Read-only file system"
    bootctl set-oneshot -> same
  So the `bootctl set-oneshot` safety net from README Phase 0 DOES NOT WORK here.
  Rollback must instead be done by editing files on the writable ESP:
    /boot/efi/loader/loader.conf        (a `default` directive)
    /boot/efi/loader/entries/*.conf     (rename/remove to change what is picked)
  Firmware otherwise boots the newest-versioned entry.
